### 🧠 How I Like to Engineer
1. **No Magic:** Never guess an API, column name, or syscall when the source code is right there waiting to be read.
2. **Real Oracles Over Mock Theater:** If a unit test only proves that a mock returns what you told the mock to return, that's not a test—it's a wish.
3. **Humans + Agents in Harmony:** Building deterministic release gates and multi-agent workflows ([`ps-skills`](https://github.com/montionugera/ps-skills)) so autonomous agents do the heavy lifting while humans keep the judgment calls.
